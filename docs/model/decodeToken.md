```cpp
std::string decodeToken(int tok)
```
---
## Basic Info
Decodes a token ID into the character string.
### Return Type
Returns an `std::string`
### Parameters
| Parameter | Type  | Use      | Optional |
|-----------|-------|----------|----------|
| `tok`     | `int` | Token ID | ❌        |

---
## Example

```cpp
// Calling the decodeToken() function
model m();
m.decodeToken(91);
```
