```cpp
inline float sigmoid(float x)
```
---
## Basic Info
Applies the Sigmoid function to an input for non-linearity.
### Return Type
Returns a `float`
### Parameters
| Parameter | Type    | Use   | Optional |
|-----------|---------|-------|----------|
| `x`       | `float` | Input | ❌       |

---
## Example

```cpp
// Calling the sigmoid() function
float sigma_oid = utility::sigmoid(-0.471781487123);
```
